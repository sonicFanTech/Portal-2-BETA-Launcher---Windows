## Overview

Portal 2 BETA Launcher is a Windows utility for organizing, launching, and researching historical Portal 2 beta builds. R-2 BETA 1.1 combines build discovery and management with hosted downloads, SHA-256 build identification, supported No-Steam fixes, first-party tool discovery, and a custom in-game overlay.

## Highlights

- Build discovery, Build Manager, Build Explorer, and Build Comparison.
- Build-specific launching and launch options.
- Hosted archive downloads with backup/Gofile fallback where available.
- SHA-256 build identification and file verification using the remote hash database.
- Cancelable downloads and automatic archive cleanup after successful extraction/installation.
- Supported No-Steam fix installation with file backups.
- 7-Zip integration for supported archive formats.
- Extra Tools page for detected first-party utilities.
- In-game overlay with movable/resizable sub-windows.
- Screenshot capture, Screenshot Manager, and preview windows.

## Controls

- `Shift + Z` — Toggle the overlay.
- `Shift + 9` — Capture a screenshot.
- `Escape` — Hide the overlay while open.
